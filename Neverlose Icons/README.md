# Документация иконок NeverLose (NeverLose Icons Guide)

Эта папка содержит полный набор официальных иконок NeverLose в формате `.svg` с понятными названиями для всех вкладок, подвкладок и элементов управления.

После загрузки содержимого этой папки в репозиторий GitHub (например, `https://github.com/<YOUR_USER>/<YOUR_REPO>/tree/main/icons/`), каждую иконку можно вызывать по прямой сылке `raw.githubusercontent.com`:
```
https://raw.githubusercontent.com/<YOUR_USER>/<YOUR_REPO>/main/icons/<ИМЯ_ИКОНКИ>.svg
```

## 3. Пример использования в NeverLose Library

```lua
-- Создание вкладки с иконкой
local AimTab = Window:AddTab({
    Name = "Aimbot",
    Icon = "https://raw.githubusercontent.com/<USER>/<REPO>/main/icons/tab_aim.svg"
})

local VisualsTab = Window:AddTab({
    Name = "Visuals",
    Icon = "https://raw.githubusercontent.com/<USER>/<REPO>/main/icons/tab_visuals.svg"
})

-- Тоггл с кнопкой трех точек (...) для поднастроек
AimTab:AddToggle({
    Name = "Auto Shoot",
    Default = false,
    Dots = true, -- включает 3 точки рядом с переключателем
    Callback = function(val)
        print("Auto Shoot:", val)
    end
})
```
